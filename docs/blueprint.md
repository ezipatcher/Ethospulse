# **App Name**: EthosPulse

## Core Features:

- Secure User Profiles: Establish personalized accounts to securely save footprints and historical progress using authenticated sessions.
- Intelligent Footprint Calculator: Multi-category assessment module to compute personal emissions based on transit, diet, and home energy consumption.
- Eco-Metrics Dashboard: Visual data visualization displaying weekly carbon trends and footprint reduction milestones.
- AI Sustainability Coach Tool: A conversational tool that uses behavioral data to reason about your habits and suggest specific carbon reduction tasks.
- Gamified Eco Challenges: Daily sustainable task lists that users can complete to earn environmental impact points.
- Community Leaderboard: Ranking system to foster competition among users based on their lifetime carbon savings.

## Style Guidelines:

- Primary color: Deep Amethyst (#8A6EEB) - chosen to evoke sophistication and the technological innovation driving environmental science.
- Background: Midnight Obsidian (#131217) - a heavily desaturated dark base that allows data metrics and cards to pop.
- Accent color: Celestial Azure (#7FAAFF) - an analogous contrast color for call-to-action buttons and positive achievement states.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward look; Body font: 'Inter' (sans-serif) for high legibility in dense metric tables.
- A spacious grid-based layout utilizing elevated bento-style cards to separate different data categories.
- Clean, thin-weight vector icons that maintain a professional and minimalist agency-inspired aesthetic.
- Micro-interactions on hover and smooth radial progress animations for metric gauges.
